# Project instructions

This is the original YouCutOwn Studio source repository. Keep changes focused.
Normal use must remain local/offline with no account, paid service, browser server,
or telemetry. Python, FFmpeg, and the native PySide6 GUI are the core architecture.

See README.md for setup and validation commands. Preserve source media, emit new
outputs, and keep one job active at a time. Use synthetic fixtures. Never commit
runtime downloads, model weights, personal settings, logs, caches, or user media.

Installer changes require a fresh source-ZIP test, hash/cache failure checks, and
confirmation that repair preserves models and outputs. Pin downloads and package
hashes. Document actual validation and material limits in PROJECT_STATUS.md.

Before editing, inspect git status and retain unrelated work. Contributions are
reviewed by the maintainer; workers must stay within their assigned task scope.
